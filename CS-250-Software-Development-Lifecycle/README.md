# CS 250 - Software Development Lifecycle 

This folder contains my completed Sprint Review and Retrospective deliverable from CS 250: Software Development Lifecycle at Southern New Hampshire University.

The project focuses on applying Agile and Scrum practices throughout the software development lifecycle using the SNHU Travel project. The deliverable reflects
on Scrum Team roles, user stories, changing requirements, communication, and the importance of continuous improvement during software development.
